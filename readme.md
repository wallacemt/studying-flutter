Este repositório reúne projetos, exemplos e exercícios desenvolvidos durante meus estudos sobre o framework Flutter. O objetivo é organizar o aprendizado, facilitar revisões e servir como referência para futuras consultas.

## Estrutura

- Cada pasta representa uma lição, módulo ou projeto específico.
- Os projetos incluem exemplos práticos, testes de widgets, configurações multiplataforma (Android, iOS, Web, Linux, macOS, Windows) e recursos utilizados nas aplicações.
- Arquivos de configuração, imagens e documentação complementar estão incluídos conforme necessário.

## Como utilizar

1. Navegue pelas pastas para encontrar o conteúdo desejado.
2. Siga as instruções de cada projeto para executar localmente (normalmente via `flutter run`).
3. Consulte os arquivos `README.md` internos para detalhes específicos de cada lição ou projeto.

## Sobre Flutter

Flutter é um framework open-source desenvolvido pelo Google para criação de aplicações multiplataforma com uma única base de código, utilizando a linguagem Dart.

## Recomendações

- Instale o [Flutter](https://flutter.dev/docs/get-started/install) e configure seu ambiente antes de executar os projetos.
- Consulte a documentação oficial para dúvidas e aprofundamento.
